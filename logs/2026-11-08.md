## AI Agent — JobMate v1.1 ([ai-agent-portfolio](https://github.com/applekiwiwi4/ai-agent-portfolio))
수업에서 배운 LangGraph, RAG, FastAPI, n8n을 실제 내 취업 준비에 쓰면서 불편했던 점을 고쳤다.

**추가한 기능**
- **지원 현황 트래커**: 공고별로 관심 → 지원 → 서류 → 면접 → 결과 상태와 메모를 표에서 바로 고친다.
  - 이미 지원한 공고는 추천 목록에서 자동으로 빠진다.
  - AI 상담의 일정 답변에도 지원 현황이 반영된다.
- **이력서 파일 업로드**: PDF, Word, 텍스트 이력서에서 보유 스킬을 찾아 모든 탭의 공고 적합도를 다시 계산한다.
  - Word 표 안의 기술 스택이나 메모장(cp949) 한글 파일도 읽는다.
- **내 공고 저장**: 새로 분석한 공고를 저장하면 검색 DB와 스킬 그래프에 바로 들어간다.
  - 개인 데이터(`data/user/`)는 git에 올라가지 않게 분리했다.
- **결과 내려받기**: 대화, 면접 노트, 첨삭 결과를 Markdown으로 받는다.
- **API**: `GET /jobs`, `GET·POST /applications`를 추가했다.

**개선**
- **응답 속도**: 스킬 그래프가 이미 정답 공고를 찾은 질문은 "근거 품질 평가" LLM 호출을 건너뛴다. 질문당 LLM 호출이 1번 줄었다.
- **n8n 워크플로**: 로컬 n8n에서 7개 노드가 모두 성공하는 것을 실제로 확인했다.
  - 주소와 Discord 웹훅은 환경변수로 뺐다.
  - 웹훅이 없으면 전송을 건너뛰는 분기를 넣었다.
- **테스트**: 17개에서 29개로 늘렸다. Streamlit AppTest 화면 테스트 3개가 포함된다.

## 혼자 자습 — Eye-to-Arm: 카메라로 부품을 찾아 로봇에게 좌표 보내기
| 단계 | 한 것 |
|---|---|
| 1 | 이진화 → `findContours`로 부품을 찾고, 중심점과 회전 각도를 구했다. 카메라 없이 가짜 부품 사진을 그려서 썼다. |
| 2 | TCP 소켓 서버/클라이언트로 기본 통신을 했다. 서버를 먼저 켜고 `SO_REUSEADDR`로 포트를 바로 다시 쓰게 했다. |
| 3 | 비전 클라이언트가 좌표를 JSON 한 줄(`\n` 구분)로 보내면, 가상 로봇 서버가 검사한 뒤 ACK나 REJECT로 답한다. |
| 4 | Homography로 픽셀 좌표를 책상 위 mm 좌표로 바꿨다. 비스듬히 찍혀 사다리꼴로 보이는 책상의 네 모서리 기준점을 썼다. |
| 5 | PySide6 GUI 한 화면에 영상, 검출 결과, 전송, 응답을 합쳤다. |

**배운 개념 (내 말로)**
- 로봇 쪽은 받은 명령을 믿지 않고 먼저 검사해야 한다.
  - 필수 항목이 있는지, 숫자인지(NaN·inf 제외), 작업 범위(300×200 mm) 안인지, 각도 범위(0~180°) 안인지 본다.
  - 하나라도 틀리면 이유를 붙여 거부한다.
  - 클라이언트에서 일부러 틀린 명령을 보내 거부되는지도 확인했다.
- 명령마다 번호표(`command_id`, uuid)를 붙인다. 네트워크 문제로 같은 명령이 두 번 와도 한 번만 움직이게 하기 위해서다(멱등성).
- 클라이언트는 타임아웃을 두고 ACK를 기다린다. 답이 없을 때 무한정 멈춰 있지 않게 하려는 것이다.
- 픽셀 좌표는 카메라 각도에 따라 왜곡된다. 바닥 평면 위의 기준점 4개로 Homography를 구하면 실제 mm 좌표로 바꿀 수 있다.

## 문제와 해결
| 문제 | 원인 | 해결 |
|---|---|---|
| (JobMate) 지원 현황을 저장해도 숫자가 바로 안 바뀜 | Streamlit은 화면을 먼저 그린 뒤에 저장 코드가 실행됐다. | 저장을 버튼 콜백으로 옮겨 화면이 갱신되기 전에 실행되게 했다. |
| (JobMate) n8n이 API에 연결하지 못함 | `localhost`가 IPv6(`::1`)로 해석되는데, API는 IPv4에서만 열려 있었다. | 주소를 `127.0.0.1`로 고정했다. |
| (JobMate) 다른 버튼을 누르면 첨삭·피드백 결과가 사라짐 | Streamlit은 버튼을 누를 때마다 스크립트 전체를 다시 실행한다. | 결과를 화면 상태로 유지하도록 고쳤다. |
| (Eye-to-Arm) 서버를 껐다 켜면 포트가 사용 중이라고 나옴 | 직전 연결이 아직 정리 중(TIME_WAIT)이었다. | `SO_REUSEADDR` 옵션을 켰다. |
| (Eye-to-Arm) 사진 속 거리와 실제 거리가 안 맞음 | 카메라가 비스듬해서 책상이 사다리꼴로 찍혔다. | 네 모서리 기준점으로 Homography를 구해 mm 좌표로 변환했다. |

## English — Snacks 복습
- 영상: [Talking about snacks](https://www.bbc.co.uk/learningenglish/english/features/real-easy-english/251003)
- 표현
  - **could do with ~**: ~가 있으면 좋겠다
    - *I could really do with a snack because it's not quite lunchtime.*
  - **loads of**: 아주 많은 (`a lot of`의 구어체)
  - **naughty** (음식): 몸에 안 좋지만 맛있는 것
  - **It depends**: 그때그때 달라
  - **have a nibble of ~**: ~를 조금씩 집어 먹다
  - **crisps**: (영국) 감자칩 = (미국) chips
  - **silly**: 우스운, 엉뚱한
  - **as well**: 또한 (문장 끝)
  - **the rest of ~**: ~의 나머지
  - **ingredients**: 재료
  - **guilty pleasure**: 죄책감이 들지만 좋아하는 것
- 말하기·쓰기
  1. I could really do with a coffee right now.
  2. I like to have a nibble of crisps while I study.
  3. Late-night ramen is my guilty pleasure.

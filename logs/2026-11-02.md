## ROS — `r2r_ws`: 도메인 ID와 영상 토픽
**배운 개념 (내 말로)**
- `ROS_DOMAIN_ID`는 같은 네트워크의 ROS 2 노드들을 묶는 방 번호다. 실습실에서는 `13`을 쓴다. 번호가 같은 노드끼리만 서로 보이니, 다른 사람 로봇과 토픽이 섞이지 않는다.
- 이미지도 하나의 토픽이다. OpenCV 이미지(ndarray, BGR)를 `cv_bridge`로 `sensor_msgs/Image`로 바꾼 뒤 `/image_raw`로 발행한다.
- 파라미터는 노드 안에서 `declare_parameter`로 기본값을 정한다. 그다음 YAML 파일과 `--ros-args -p`로 덮어쓸 수 있다. YAML 구조는 `노드이름 → ros__parameters → 값`이고, 실수형 값은 `30.0`처럼 소수점을 붙여야 한다.
- 런치 파일(XML)은 노드 실행과 파라미터 파일 지정을 한 번에 한다. 단, `setup.py`의 `data_files`에 `launch/`, `config/`를 넣어야 설치 폴더로 복사되어 찾을 수 있다.

**실행한 것**
```bash
colcon build --symlink-install --packages-select my_opencv_tutorials
ros2 launch my_opencv_tutorials bringup_cv.launch.xml
ros2 run my_opencv_tutorials img_publisher --ros-args -p width:=320 -p height:=240 -p frame_rate:=10.0

ros2 topic hz /image_raw          # 실제 발행 주기 확인
ros2 topic bw /image_raw          # 대역폭 확인
ros2 param list /image_publisher
ros2 param get /image_publisher width
ros2 param dump /image_publisher
ros2 run rqt_image_view rqt_image_view /image_raw
ros2 run rqt_reconfigure rqt_reconfigure
```

**결과**
- 카메라가 없을 때는 테스트 패턴이 `/image_raw`로 발행되었고, rqt_image_view로 영상을 확인했다.
- `-p`로 해상도와 frame_rate를 바꾸면 `topic hz` 값과 화면 크기가 같이 바뀌었다.

## ROS — `ros2_ws`: 토픽 · 서비스 · 액션
**배운 개념 (내 말로)**
| 방식 | 모양 | 언제 쓰나 |
|---|---|---|
| 토픽 | 발행자 → 구독자, 계속 흘려보냄 (1:N) | 센서 값, 영상, 속도 명령처럼 끊임없이 오는 데이터 |
| 서비스 | 요청 → 응답 한 번 (클라이언트/서버) | "지금 상태 알려줘"처럼 짧게 묻고 바로 답받는 일 |
| 액션 | 목표 → 중간 피드백 → 최종 결과, 도중 취소 가능 | "저기까지 가"처럼 오래 걸리고 진행 상황이 필요한 일 |

- 예제 패키지(`examples_rclpy_minimal_publisher/subscriber`, `minimal_service/client`, `minimal_action_server/client`)로 세 가지 방식의 기본 구조를 봤다.
- 직접 정의한 인터페이스는 `amr_agent_interfaces` 패키지에 있다. `.srv`(GetRobotStatus, ResolveLocation)와 `.action`(GoToNamedPlace, LiftControl, ExecuteMission)은 각각 서비스와 액션으로 쓰인다.

## 문제와 해결
| 문제 | 원인 | 해결 |
|---|---|---|
| 런치 파일·YAML을 못 찾음 | `setup.py`의 `data_files`에 `launch/`, `config/`가 빠져 있었음 | `glob('launch/*')`, `glob('config/*')`를 추가하고 다시 빌드 |
| 실수형 파라미터 타입 오류 위험 | `frame_rate: 1`처럼 정수로 쓰면 double로 선언한 값과 타입이 다름 | YAML에 `1.0`처럼 소수점을 붙여서 씀 |

## AI Agent — 2-3 RAG 실습 (사내 정책·매뉴얼 Q&A)
**배운 개념 (내 말로)**
- 2-2에서 배운 RAG 5단계를 함수 하나씩으로 나눠 만들었다.
  - `load_docs`: 읽기
  - `split_docs`: 자르기
  - `build_index`: 임베딩과 저장
  - `search`: 찾기
  - `ask`: 답하기
- **파일 이름을 메타데이터로 쓴다.** `policy_`, `manual_`, `faq` 앞부분을 `doc_type`으로 저장해 두면 `filter={"doc_type": {"$in": [...]}}`로 정책 문서에서만 찾을 수 있다.
- **자르기는 두 번 한다.** `MarkdownHeaderTextSplitter`로 `##` 소제목마다 자르고, 400자가 넘으면 `RecursiveCharacterTextSplitter`로 다시 자른다. 조각마다 앞에 `[문서 제목 > 소제목]` 머리말을 붙인다.
- **`reset_collection()`으로 중복 저장을 막는다.** 색인을 다시 만들 때 이전 조각이 남지 않게 한다.
- **근거만 쓰게 하는 프롬프트**
  - 근거에 없으면 "확인 후 안내드리겠습니다"라고 답하게 했다.
  - 답 끝에 `(출처: 파일명)`을 붙이게 했다.
  - 검색된 조각은 `[근거1] (파일명)` 형식으로 묶어서 넘겼다.
- **검색 품질은 LLM 없이 잰다.** Hit Rate는 정답 문서가 상위 k개 안에 들어오는 비율이다. LLM을 부르지 않으니 API 한도를 쓰지 않는다.
- Chroma의 점수는 유사도가 아니라 거리다. 작을수록 가깝다.

**내가 만든 것**
- `src/csagent/rag.py`
- `scripts/04_build_index.py` (색인 만들기)
- `scripts/05_eval_retrieval.py` (Hit Rate 측정)
- `scripts/06_ask_docs.py` (근거 기반 답변)

**결과**
- 검색 평가(질문 12개, `questions_eval.csv`)

| k | Hit Rate |
|---|---|
| 4 | **12/12 = 100%** |
| 1 | **10/12 = 83%** |

- k=1에서 틀린 2건은 모두 1위가 `faq.md`였다.
  - "반품 왕복 배송비"의 정답은 `policy_refund_exchange.md`였다.
  - "필터 교체 주기"의 정답은 매뉴얼이었다.
  - FAQ가 정책과 매뉴얼의 내용을 짧게 다시 적어 둔 문서라서, 질문과 더 비슷해 보인 것이다. 정답 문서는 2~4위 안에는 들어왔다.
- "제습기 E6 오류"처럼 짧은 기호가 들어간 질문도 1위로 매뉴얼을 찾았다.
- 근거 기반 답변(`06_ask_docs.py`)

| 질문 | 답 | 출처 |
|---|---|---|
| 단순 변심 반품 배송비 | 왕복 6,000원을 고객이 부담 | policy_refund_exchange.md |
| 로봇청소기 5GHz 와이파이 | 2.4GHz만 지원, 5GHz 연결 안 됨 | manual_roboclean_x.md |
| 직원 할인 (문서에 없음) | "해당 내용은 확인 후 안내드리겠습니다" | 지어내지 않음 |

- 1-6 답변 초안 체인은 "제주 배송비"를 물으면 추측했다. 이제는 문서의 숫자와 출처로 답한다.

## ROS — 자율주행 과정 1일차 ② 실습 (리눅스와 ROS 2 설치, 노드끼리 대화)
**배운 개념 (내 말로)**
- **WSL2 자원 설정**: WSL은 기본으로 PC 메모리의 절반을 쓴다. `.wslconfig`에 `memory`, `processors`, `swap`을 정해 두면 시뮬레이터가 Windows 전체를 멈추게 하는 일을 막을 수 있다. 바꾼 뒤에는 `wsl --shutdown`으로 다시 켠다.
- **그래픽 가속 확인**
  - `glxinfo -B`에서 `D3D12 (GPU 이름)`이 보이면 GPU가 그린다.
  - `llvmpipe`면 CPU가 그리는 상태다. 이러면 Gazebo가 실제보다 느리게 돌아 튜닝 결과를 믿을 수 없다.
  - Ubuntu 안에 그래픽 드라이버를 따로 깔면 안 된다. Windows 쪽 드라이버만 있으면 된다.
- **실습 코드는 Ubuntu 홈(`~/`)에 둔다.** `/mnt/c` 아래에서 빌드하면 매우 느리다.
- **ROS 2 설치 순서**
  1. 로케일을 UTF-8로 맞춘다.
  2. ROS 저장소를 등록한다(`ros2-apt-source`).
  3. `ros-jazzy-desktop`(RViz·rqt 포함)과 `ros-dev-tools`(colcon, rosdep)를 설치한다.
  4. `source /opt/ros/jazzy/setup.bash`를 적용한다.

**실행한 것**
```bash
wsl -l -v                      # VERSION 2 확인 (PowerShell)
lsb_release -a                 # Ubuntu 24.04 noble
xeyes                          # 리눅스 창이 Windows 화면에 뜨는지
glxinfo -B | grep -E "renderer|version string"
printenv ROS_DISTRO            # jazzy
ros2 run demo_nodes_cpp talker
ros2 run demo_nodes_py listener
ros2 run turtlesim turtlesim_node
ros2 topic echo /turtle1/pose
ros2 service call /spawn turtlesim/srv/Spawn "{x: 2.0, y: 2.0, theta: 0.0}"
ros2 action send_goal /turtle1/rotate_absolute turtlesim/action/RotateAbsolute "{theta: 1.57}"
ros2 param set /turtlesim background_r 150
```

**결과**
- talker가 발행한 메시지를 listener가 받았다(Topic).
- turtlesim에서 통신 4가지를 직접 확인했다.
  - Topic: 위치 구독
  - Service: 거북이 추가
  - Action: 절대 각도 회전과 진행 피드백
  - Parameter: 배경색 변경

## 문제와 해결
| 문제 | 원인 | 해결 |
|---|---|---|
| k=1에서 정답 문서 대신 `faq.md`가 1위로 나옴 (2건) | FAQ가 정책·매뉴얼 내용을 질문 형태로 요약해 둔 문서라 질문과 더 비슷하다. | k=4로 늘리면 정답 문서가 근거에 함께 들어가 100%가 된다. 답변에는 k=4를 쓰기로 했다. 다음에는 정책 질문에 `doc_types=["policy"]` 필터를 써 보거나, FAQ 조각에 원본 문서 이름을 붙여 볼 생각이다. |
| 문서에 없는 질문에도 `(출처: faq.md)`가 붙음 | 프롬프트가 "답변 끝에 출처를 적는다"를 항상 지키려고 했다. | 답은 지어내지 않았으니 큰 문제는 아니다. 프롬프트에 "근거가 없으면 출처를 적지 않는다"를 더하면 된다. |
| 시뮬레이터가 느릴 수 있음 | WSL이 GPU 대신 CPU(llvmpipe)로 그리면 3D가 매우 느리다. | `glxinfo -B`로 renderer를 먼저 확인했다. llvmpipe면 Windows 그래픽 드라이버를 업데이트하고 `wsl --shutdown` 후 다시 확인한다. |

## English (30 min) — Housemates
- 영상: [Talking about housemates](https://www.bbc.co.uk/learningenglish/english/features/real-easy-english/250905)
- 새 단어
  - housemate / roommate (같이 사는 사람), share a flat (집을 같이 쓰다. 미국은 apartment)
  - get along with ~ (~와 잘 지내다), split the bills (공과금을 나누다)
  - It drives me crazy. (미치겠어.)
- 대화: *We split the bills, but one guy never cleans. — That would drive me crazy.*
  - `would`는 "나라면 그럴 것 같다"는 가정을 나타낸다.
- 말하기·쓰기 (같이 살 때 규칙 3개)
  1. We split the bills equally every month.
  2. Everyone does the dishes after using the kitchen.
  3. Don't put off cleaning the communal areas.

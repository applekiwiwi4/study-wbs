## AI Agent — 1-2 개발 환경 설정 → 1-4 첫 LLM 호출
**배운 개념 (내 말로)**
- 프로젝트마다 가상환경(`.venv`, Python 3.12)을 따로 만든다. 패키지 버전이 다른 프로젝트와 섞이지 않게 하려는 것이다. 필요한 패키지는 `requirements.txt` 한 파일에 모아 두고 한 번에 설치한다. 오늘 설치한 것은 LangChain, LangGraph, Chroma, HuggingFace 임베딩, FastAPI, Streamlit 등 17개다.
- API 키는 코드에 쓰지 않고 `.env`에 둔다. `.env`는 `.gitignore`에 넣어 GitHub에 올라가지 않게 한다. 다른 사람이 볼 수 있는 견본은 `.env.example`로 따로 둔다.
- `config.py`의 `get_llm()` 하나로 모델을 만든다. `.env`의 `LLM_PROVIDER`만 바꾸면 다른 코드는 그대로 둔 채 Gemini, Groq, OpenRouter, Ollama 사이를 오갈 수 있다. 제공자에 덜 묶이게 만드는 구조다.
- LLM을 호출하는 방법 네 가지를 해 봤다.
  - `invoke("질문")`: 가장 간단하게 질문하고 답을 받는다.
  - `("system", ...)` + `("human", ...)` 메시지: 역할(고객지원 상담원)을 정해 주고 요청한다.
  - `temperature` 비교: 0이면 매번 비슷한 답, 1이면 매번 다른 답이 나온다. 상담 답변처럼 일관성이 필요한 일은 낮게 둔다.
  - `stream()`: 답이 만들어지는 대로 조금씩 출력한다. 채팅 화면의 타이핑 효과가 이것이다.
- 응답의 `usage_metadata`로 토큰 사용량을 볼 수 있다. 무료 한도를 관리할 때 필요하다.

**내가 만든 것 / 바꾼 것**
- `cs-agent/` 폴더 구조를 잡았다: `.venv`, `requirements.txt`, `data/`, `src/csagent/`, `scripts/`.
- 만든 파일
  - `src/csagent/config.py`: 경로 상수, `get_llm()`, `get_embeddings()`
  - `scripts/01_hello_llm.py`
- `.env`의 `LLM_PROVIDER=groq`로 바꾸고, Groq 모델을 `openai/gpt-oss-120b`로 지정했다. 임베딩은 내 PC에서 돌리는 `local`(multilingual-e5-small)로 두었다.
- Git 커밋 3개를 남겼다.
  - 프로젝트 시작: 환경 설정과 실습 데이터
  - `__init__.py` 파일 이름 수정
  - LLM 설정과 첫 호출

**결과**
- `python scripts/01_hello_llm.py`로 요약 응답, temperature 비교, 스트리밍 출력을 확인했다.
- `git check-ignore`로 `.env`가 커밋 대상에서 빠지는 것도 확인했다.

## ROS — 2-3 YAML 파라미터·launch, 2-4 HSV 변환기
**배운 개념 (내 말로)**
- 런치 파일 하나에 노드를 여러 개 띄울 수 있다. 예: 영상 발행 노드와 처리 노드(Canny, HSV)를 함께 실행하고, 같은 `cv_params.yaml`을 각각 넘긴다.
- 처리 노드는 `/image_raw`를 구독해 가공하고 새 토픽으로 발행한다(`/image_edge`, `/image_hsv`). 하나의 노드가 구독자이면서 발행자다.
- 파라미터에 범위(`IntegerRange`)를 붙여 선언하면 rqt_reconfigure에 슬라이더로 나온다. 실행 중에 임계값을 바꿔 결과를 바로 볼 수 있다.

**실행한 것**
```bash
ros2 launch my_opencv_tutorials edge_detect.launch.xml
ros2 run rqt_image_view rqt_image_view /image_edge
ros2 launch my_opencv_tutorials hsv_converter.launch.xml
ros2 run rqt_reconfigure rqt_reconfigure
```

## 문제와 해결
| 문제 | 원인 | 해결 |
|---|---|---|
| `csagent` 패키지를 불러오지 못함 | 파일 이름이 `__init__py`로 점(`.`)이 빠져 있었다. 이 파일이 없으면 폴더가 파이썬 패키지로 인식되지 않는다. | `__init__.py`로 이름을 고치고 따로 커밋했다. |
| Gemini 기본 설정으로 호출이 잘 되지 않음 | 교재 견본의 모델 이름이 지금 쓸 수 있는 모델과 다르고, 무료 한도도 빡빡했다. | `get_llm()` 구조 덕분에 `.env`에서 `LLM_PROVIDER=groq`로 한 줄만 바꿔서 해결했다. 모델 이름도 현재 것으로 맞췄다. |
| API 키가 GitHub에 올라갈 위험 | 첫 커밋 전에 `.env`가 폴더에 있었다. | 첫 커밋 전에 `.gitignore`부터 만들어 `.env`, `.venv/`, `chroma_db/`를 제외했다. |
| HSV 런치를 실행해도 변환 노드가 동작하지 않음 | `hsv_converter.py`가 아직 빈 파일이다. | 다음에 노드 코드를 채울 예정이다. Canny 노드를 참고하면 구독 → 변환 → 발행 구조가 같다. |
